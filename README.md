# AI Article Summarizer

An AI-powered article summarizer built using Hugging Face Transformers and Gradio.

## Features

- Summarizes long articles
- Adjustable summary size
- Interactive UI with Gradio
- Uses Hugging Face NLP models

## Tech Stack

- Python
- Hugging Face Transformers
- Gradio
- PyTorch

## Run Locally

```bash
pip install -r requirements.txt
python app.py
```

## Model Used

sshleifer/distilbart-cnn-12-6
